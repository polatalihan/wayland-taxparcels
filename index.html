ABOUT THE EXPLORER

Wayland Parcel & Assessed Value Explorer

This dashboard is designed for an economic-development scan of Wayland. It combines parcel geometry with the assessor extract in the supplied dataset and makes assessed value, land use, and zoning directly queryable.

Interpretation notes

  • Total assessed value is the assessor's value for land and structures; it is not a market-price estimate.
  • Land use uses the Massachusetts DOR property type code. Four-character local variants are grouped using the first three digits of the DOR code, while the original local code remains visible.
  • Last sale price is shown for reference only. Assessor files can contain nominal or non-arm's-length sales, including $1 transactions.
  • Building area definitions can vary across CAMA systems and property types, so comparisons should be treated as screening-level analysis.
  • Some parcel polygons do not have a populated assessor match in the supplied extract; these remain on the map as “No assessor data.”
